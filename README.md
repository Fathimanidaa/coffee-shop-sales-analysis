# Coffee Shop Sales Analysis

## Project Overview
This project analyzes coffee shop sales data to understand sales performance, customer ordering patterns, product performance, and store-level trends. The dashboard presents key metrics and interactive visualizations to support business decision-making.

## Tools Used
- **Microsoft Excel:** Sales dashboard and data visualization
- **MySQL:** Data preparation, SQL queries, aggregations, and analysis

## Dashboard Preview

![Coffee Shop Sales Dashboard](https://github.com/Fathimanidaa/coffee-shop-sales-analysis/blob/main/coffee_shop_sales_%20analysis.png?raw=true)


## Key Performance Indicators
- Total Sales
- Total Orders
- Total Quantity Sold
- Month-over-Month Growth

## Analysis Covered
- Sales trends over time
- Weekday versus weekend sales
- Sales by store location
- Sales by product category
- Sales by product type
- Sales by day of the week and hour
- Daily sales compared with average sales

## SQL Skills Demonstrated
- Data type conversion and date/time formatting
- Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
- Conditional logic using `CASE`
- Grouping and sorting using `GROUP BY` and `ORDER BY`
- Window functions such as `LAG()`
- Month-over-month growth calculations

## Project Files
- `dashboard/` — Dashboard screenshot
- `sql/` — SQL queries and explanations
- `presentation/` — Project presentation

## Conclusion
This project demonstrates practical skills in SQL-based data analysis, KPI calculation, data visualization, and presenting sales insights in a business-friendly format.
